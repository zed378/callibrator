# 2026-09-30 — P10-03: the landing, rebuilt dark, bilingual, and true

**Card:** P10-03 · **ADR:** ADR-098, Amendment 1 rows 3–5, 11 · **Status:** DONE in code — release items open (below)

## Built

- `frontend/src/app/page.tsx` is a **server component** (it was `"use client"`), exporting its own `generateMetadata` from the dictionary. Client JavaScript on `/`: the header menu button (`components/public/MobileMenu.tsx`) and the workflow story's one `IntersectionObserver` (`components/public/landing/WorkflowStory.tsx`). **No animation library**: GSAP, ScrollTrigger, SplitText, Lenis and Motion are not imported by the public page graph (pinned by a test). No `ScrollReveal`: no text is ever hidden, before or after hydration.
- Sections in doc 20 §6 order: header (anchors, language form, Sign in, Contact) · hero (serif `<h1>`, lead, contact CTAs, the always-present request-access link, product screenshot over the precision motif, captioned *Contoh data*) · the problem · workflow story (six steps, a sticky product crop on desktop, a crop under each step on mobile) · capabilities · compliance and security ("supports", the disclaimer) · public verification (QR explanation + phone mock-up of a real verdict) · how we work · FAQ (native `<details>`) · contact · footer (only links with a destination; `© {year} Device Calibrator`). One `<main>`, one `<h1>`, a skip link.
- Contact channels from `NEXT_PUBLIC_CONTACT_WHATSAPP` / `NEXT_PUBLIC_CONTACT_EMAIL` (`components/public/contact.ts`): `wa.me` with prefilled text, `mailto:` with a subject; **an empty or invalid value hides the channel**; with neither, the request-access link becomes the primary button.
- Product screenshots (`frontend/public/marketing/product/*.webp`, 7 files, 30–63 KB each; hero 1440×945, 46 KB): captured 2026-09-30 at 2× from the product's own dark dashboard and `/verify` on a disposable local stack (a `pgvector/pgvector:pg18` and a `redis:7` container, the backend and frontend from source), seeded with `seed-demo` plus seven invented devices (`CONTOH-*` serials, invented makers). Sidebar and top bar cropped out (the sidebar still says "HDC CALLIBRATOR", which Q-43 forbids on public surfaces). The demo certificate's `valid_until` was moved forward in that throwaway database so the phone shows a VALID verdict. Registered in doc 20 §12.
- Deleted with the old page: every `components/landing/*` section, `hero/`, `_shared/MediaFrame.tsx`, `_shared/Underline.tsx`, `data/landing.ts`, `components/motion/{Counter,Marquee,SplitHeading,TiltCard}.tsx`, the last seven Pexels photos.
- `app/verify/page.tsx`: `?number=` → `/verify/<number>` redirect, so the lookup form works without JavaScript — the form itself is behind `CERTIFICATE_LOOKUP_ENABLED = false` (`lib/publicFeatures.ts`) until P10-14 is DONE.
- `lib/socket.ts` imports `socket.io-client` on first connection instead of at module load: `authStore` imports the module for `disconnectSocket()`, which put ~17 KB gzip of Socket.IO on every page, the landing included. `lib/socket.test.ts`, `stores/*`, kanban realtime: 402 tests pass.
