# P22-10c2: the `/field` app — one document, its screens, the field store, the shell guard, the bundle budget; an engine lost-update fixed

**Date:** 2026-10-12 · **Task:** P22-10c2 (Phase 22; P22-10c = c1 / c2 / c3, ADR-127 Am. 3 § 1) · **Specs:** [`P19-08`](../specs/P19-08-offline-field-capture.md) § 3, § 4.3, § 4.4, § 8, § 9.6, § 11 – § 13, § 15; ADR-127 + Am. 1 – 4 · **Base:** after P22-10c1

> Frontend, plus one zod-free contracts module. The browser suite on the compose stack (§ 16.3) and the real-device script (§ 16.5) are **P22-10c3**.

## Built

| Area | What |
|---|---|
| Route | `app/(app)/field/`: `layout.tsx` (the only page linking the manifest; `appleWebApp`), `page.tsx` (the dictionary only: `field.`, `ipm.`, the catalogue's section and outcome names), `FieldClient.tsx` (the island, wired to the browser). Rendered per request under the nonce CSP; **no tenant data** in the document. |
| Store (`field/ui/fieldStore.ts`) | Zustand (vanilla), one per app instance, over the c1 runtime. **Boot:** online, `/auth/verify` + the profile guard (others' sets dropped, AM-23), the user's runtime when the registry has their row (profile stored in `meta`), a first sync; offline, the registry row holding data names the user and its stored profile stands in (nothing sent); none → "offline, no data"; a browser without IndexedDB / Web Crypto → setup. **Prepare:** facility rule, another user's outbox blocks, worker registered, download with progress; the app stays on Settings until it completes. **Sync:** the cycle; a `scope_changed` purge re-downloads the stored choice (a bound user's NEW facility); the catalogue refreshed with `If-None-Match`; the "to sign" list read; synced captures removed once re-read (§ 9.1). **Updates:** a waiting worker, or one installed under a controller, offers "Update now"; `controllerchange` reloads (§ 13). Turn off, wipe, QR lookup (local first, then `by-qr` online), capture lifecycle through the engine. |
| Shell (`FieldApp.tsx`, `nav.ts`, `context.tsx`) | Screens as client state in `?view=&id=&ref=` (`pushState`; back works offline); the outbox count and the connection (status-tone registry: `fieldConnection`) on every screen; one `<main>`; each screen's `<h1>` focused and announced; sync on start, `online`, visible, "Sync now", the worker's `cf-sync`. |
| Screens | **Home** (outbox, attention, retry wait, last sync, each facility's expiry, another user's count, offline note, "to sign"); **Settings** (missing features, prepare with sizes first, storage grant and quota, eviction warning, update, turn off refused with an outbox, admin wipe with typed WIPE, install per platform); **Scan** (camera via `BarcodeDetector` only, typed code, search); **Device**; **Register** (bound: no QR, no facility; rooms chosen, never created offline; two photos; then an IPM that waits for it); **Capture** (P22-03's stepper and `ItemField` over the local catalogue, local write-through on every change, header + evidence photos, review with what is missing); **Outbox** (every § 9.6 code explained with its actions; discard needs DISCARD); **Sign** (online links to the report page; never a credential on the phone). |
| Budget (§ 15) | Capture, Settings, Register, Outbox, Sign and the QR scanner load on demand; `SCOPE_LOSS_CODES` moved to a zod-free `@callibrator/contracts/scopeLoss` (re-exported by `clientFacilities`); UI imported per component, not through the barrel. **The warm-up** (§ 4.3): once the worker controls the page, every lazy module is imported and every `/_next/static` file is fetched again through the worker (`warmStatic`). `bundle-budget.json` gains `/field` (163 / 188) and `/dashboard` (191 / 220). |
| i18n | 220 `field.*` keys, Indonesian and English. |
| **Engine fix (P22-10a defect)** | `engine.ts` has no per-capture serialisation: an edit, a photo added and the runner's confirmation each read the capture and wrote it back, so the later write lost the earlier one. **Found by the capture component test:** a photo vanished after a header edit. Every read-modify-write now runs under a per-capture lock; the network send stays outside it. |
| Manifest | `public/manifest.webmanifest` (P22-10b) named the installed app "Callibrator — Lapangan"; Q-43: the product name is "Device Calibrator". Now "Device Calibrator — Lapangan" / "Calibrator"; `fieldInstall.guard` asserts it (the copy guard does not scan the manifest). |
| Other | `idbStore.putPhoto` reads a blob through a FileReader where `Blob#arrayBuffer` is missing (older WebViews; jsdom). Status-tone domains `fieldCapture`, `fieldConnection`. |
