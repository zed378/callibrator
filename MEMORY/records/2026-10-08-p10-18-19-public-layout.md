## 1. P10-19 — `/request-access`, `/forgot-password`, `/invitation` load their API layer on demand

- `frontend/src/components/public/authApi.ts` (new): `loadAuthService = () => import("@/api/services/auth.service").then(m => m.authService)`.
- `frontend/src/hooks/usePrefetchOnFirstInput.ts` (new): the `/login` prefetch of the 2026-10-07 addendum as a hook — the first `keydown` / `pointerdown` / `touchstart` **inside `<main>`** fires `load()` once, then the listeners go. Not on focus (`/forgot-password`'s email field autofocuses, as `/login`'s does); not from the theme toggle or language form outside `<main>`.
- `RequestAccessForm.tsx`, `ForgotPasswordForm.tsx`, `InvitationForm.tsx`: the static `authService` import became the hook plus `await loadAuthService()` at the point of use. `RequestAccessForm` keeps a type-only import of `AccessRequestInput`. A failed import lands in each form's existing `catch` (status `null` → the "network" message).
- `app/(public)/login/hooks/useLoginForm.ts`: its inline listener effect replaced by the same hook (same behaviour; its `lazyAuth.p1017` test unchanged and green).
- **Requests unchanged, proved:** `requestAccess.p1006`, `forgotPassword.p1009` and `invitation.p1015` mock the API client underneath the service and assert the exact bodies (`POST /api/v1/access-requests` with the contract body, `/auth/send-otp`, `/auth/reset-password`, `/auth/invitation/accept`) — all green, unedited.
- **New tests:** `app/(public)/{request-access,forgot-password,invitation}/__tests__/lazyAuth.p1019.test.tsx` (3 each): not loaded at render or by input outside `<main>`; loaded once at the first key press inside `<main>` and the three listeners removed; a submit awaits the import and reaches the service. **Fail-before:** with a static `import "@/api/services/auth.service"` added back to `ForgotPasswordForm`, its suite fails (1 of 3).
- **Bundle:** first-load JS **147.8 / 146.8 / 146.4 → 127.6 / 126.7 / 126.3 KB brotli** (170.7 / 169.7 / 169.3 → 148.5 / 147.6 / 147.1 KB gzip). Ceilings lowered **148 / 171 → 131 / 152 KB**. `/login` 130.9 → 131.1 KB (the shared hook's chunk).
