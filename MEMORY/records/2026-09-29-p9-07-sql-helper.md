## Deviation

The card specified `sql(text, bind)`; the helper is `sql(runner, text, bind)`. The runner is injected, because importing the instance would open a pool at import time and would stop the tests from passing a double. ADR-087 Amendment 12 §2 records this, with the alternatives and the bad implication.
