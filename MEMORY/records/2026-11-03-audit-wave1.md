## Recorded, no change (premise incorrect / already fixed)

- **INF-02** — nginx `proxy_read/send_timeout` 60s vs the app's
  `connect-timeout("30s")`. The proxy deliberately exceeds the app so the app's
  enveloped 408 reaches the client, never nginx's generic 504; lowering nginx to
  30s would race the app. Documented the invariant (proxy_timeout >=
  application_timeout); no value change.
